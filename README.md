# home-weather-for-m5stack-core2
This is the final repo for my Cloud and Advanced Analytics 2026 class project. The assignment was to create a home assistant / weather station using the M5Stack-Core2.

# Interacting
- See my [YouTube video](https://youtu.be/t2wQu9lDJLw)
- See the [fronted](https://caa26-project-frontend-211229885401.europe-west1.run.app)

# Links and source
Icons used: [MakinThings/Weather-Icons](https://github.com/Makin-Things/weather-icons)

Meteoswiss: [STAC API GUIDE](https://www.geo.admin.ch/en/rest-interface-stac-api) and [OGD](https://www.meteoswiss.admin.ch/services-and-publications/service/open-data.html)

# Features
- Close-to-real-time indoor and outdoor weather indicators.
- Voice-interaction using Gemini, Google Speech-to-Text, and Google TTS.

# Deploying
You will need a Google Cloud account to proceed. Both the `backend` and `dashboard_frontend` need to be deployed on Google Cloud Run.
Endpoints, API keys, and passwords have been abstracted for your convenience.
